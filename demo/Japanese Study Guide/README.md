# Japanese Study Guide

Arabic static website for Japanese learners who want a practical roadmap for:

- learning Japanese from zero
- finding work websites in Japan
- translator profiles and local ratings
- Japanese learning games
- preparing from zero to JLPT N1
- choosing language apps like Anki
- official links for JLPT, visa, study, and life in Japan

## Open

Double-click `open-site.command`, or open `index.html` in a browser.

## Files

- `index.html` - content and page structure
- `jobs.html` - job websites in Japan with explanations
- `translators.html` - translator profiles and ratings prototype
- `games.html` - Japanese learning games
- `kanji-rush.html` - browser game for drilling kanji word readings
- `kanji-grid.html` - grid matching game for dragging hiragana readings onto kanji tiles
- `roadmap.html` - study roadmap from zero to N1
- `apps.html` - Japanese language apps and why they matter
- `links.html` - important official links
- `styles.css` - responsive visual design
- `script.js` - page interactions, games, job search, translator profiles
- `kanji-rush.js` - Kanji Rush game loop and drag/drop reading tiles
- `kanji-grid.js` - Kanji Match Grid matching, replacement, and tile swapping
- `open-site.command` - macOS launcher that opens the site
